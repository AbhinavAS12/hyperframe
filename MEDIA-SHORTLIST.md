# Envato Elements shortlist — Dubai South investor video

Curated via the Envato Elements catalog. These need a licensed download through
your own logged-in Envato Elements session (this cloud session has no download/
license tool — only catalog search), then dropped into this project.

## How to wire a clip in once downloaded

1. Download the MP4(s) you want from the links below (your Envato Elements
   subscription covers the license).
2. Create `assets/video/` in this project and drop the files in, e.g.
   `assets/video/dxb-skyline-aerial.mp4`.
3. Get the files to this session — either push them straight to the
   `claude/amazing-ramanujan-hoqzi6` branch on GitHub (they'll show up here on
   the next pull), or re-attach them in chat and I'll place them.
4. I'll swap the matching generative background for a `<video muted>` layered
   behind the existing map/data graphics, with `data-start`/`data-duration`
   matched to that scene's timing — the generative SVG/CSS layer (boundary
   draw-ins, count-ups, badges) stays on top as the data layer; the footage
   becomes the atmosphere behind it. Re-run `npm run check` after.
